| マークダウン要素 | 保存時（HTML→MD） | 開く時（MD→HTML） |
|---|---|---|
| 見出し（#〜######） | Turndownでh1〜h6→#〜###### | markedで#〜######→h1〜h6 |
| 段落 | <p>→空行 | 空行→<p> |
| 箇条書きリスト | <ul>/<ol>/<li>→- , * , + | -, *, + → <ul>/<ol>/<li> |
| チェックリスト | <input type="checkbox">→- [ ] / - [x] | - [ ] / - [x] → <input type="checkbox"> |
| テーブル | <table>→GFMテーブル記法 | GFMテーブル→<table>（Notion形式はpreprocessNotionMarkdownで正規化） |
| コードブロック | <pre><code>→```lang | ```lang→<pre><code>（highlight.jsでハイライト） |
| インラインコード | <code>→`code` | `code`→<code> |
| 引用 | <blockquote>→> | > → <blockquote> |
| 画像 | <img>→![]()（asset://は相対パスに変換、Base64はファイル保存） | ![]()→<img>（相対パスはasset://に変換） |
| 数式（KaTeX） | <span class="math-inline">→$ $、<span class="math-display">→$$ $$ | $ $/$$ $$→<span class="math-inline/math-display">（KaTeXで描画） |
| Mermaid | <div class="mermaid-container">→```mermaid | ```mermaid→<div class="mermaid-container">（mermaid.jsで描画） |
| トグル（details/summary） | <details><summary>→<details>記法 | <details>記法→<details><summary> |
| 目次（TOC） | <div class="toc-container">→**📑 目次** | **📑 目次**→<div class="toc-container"> |
| 改行 | <br>→（段落内は無視、セル内は<br>維持） | （段落内の改行は無視、テーブルセル内は<br>に変換） |
| 画像貼付（Base64） | <img src="data:...">→ファイル保存＋パス差し替え | ![]()でBase64は不可（貼付時のみ） |

---
- 保存時はTurndownのカスタムルールでHTML→MD変換。
- 開く時はmarked+preprocessNotionMarkdown等でMD→HTML変換。
- 画像・埋め込み・数式・Mermaid等は追加処理あり。
- テーブルやチェックリストはGFM拡張・Notion特殊形式に注意。
