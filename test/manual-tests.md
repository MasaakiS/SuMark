# 手動テスト必須項目一覧

本プロジェクトでは、E2E自動化が困難な一部の機能について、品質担保のため手動テストを必須としています。下記の項目はリリース前に必ず手動で確認してください。

---


## KaTeX数式描画

### テスト内容
- Markdownエディタに以下の内容を入力し、KaTeX数式が正しく描画されることを確認する。

```
$$E=mc^2$$
```

### 確認ポイント
- 数式入力後、エディタ下部またはプレビュー領域にKaTeX数式（美しくレンダリングされた数式）が正しく表示されること
- 数式のパースエラーが発生しないこと
- 手動操作（コピペ・分割入力・Enter等）で描画がトリガーされること

### 備考
- E2E自動化では描画トリガやDOM構造の問題で安定検証不可のため、手動テスト必須
- 詳細経緯は test/playwright/10-tauri-ext-access.spec.js のコメント参照

---
